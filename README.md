# 5kings bot

Автономный бот для [5kings.ru](https://5kings.ru): **большой лес** + **королевские хаосы 3×3**.

## Сдача заказчику (основное)

Один самодостаточный файл Tampermonkey — **без** `@require` и без загрузки кода со сторонних сайтов:

[`tampermonkey/5kings-bot.user.js`](tampermonkey/5kings-bot.user.js)

**Tampermonkey:** вставьте [`tampermonkey/5kings-bot.user.js`](tampermonkey/5kings-bot.user.js) **v1.2.0** в редактор → Ctrl+S → `https://5kings.ru/game.html`.

В Chrome 138+ это **не заработает**, пока на странице расширения Tampermonkey не включён тумблер **«Разрешить пользовательские скрипты»**. Иначе скрипт сохраняется, но Chrome его не выполняет.

1. `chrome://extensions` → Tampermonkey → **Подробнее**.
2. Включить **«Разрешить пользовательские скрипты»** (и само расширение, если выключено).
3. Вставить файл в редактор TM → Ctrl+S → F5 на `game.html`. Зелёная полоса сверху = скрипт живой.

Дальше: большой лес / колизей → **Старт лес** или **Старт** (хаосы).

### Что умеет (по ТЗ)

| Модуль | Функции |
|--------|---------|
| Лес | Бродилка большого леса: дерево / руда / травы / грибы, поиск + инструмент + крафт, лечение (свиток / абилка / ожидание) |
| Капча | Детект → стоп + звук + «Продолжить»; хук под будущий RuCaptcha |
| Хаосы | Комплект KH, вход/создание заявок 3×3 |
| Бой | Сближение, удары/блоки по 5 зонам, магия/хил, humanizer |
| Лицензия | Опциональная привязка к UserID |

### Важно

- Только **большой лес** (не городской).
- Автораспознавание капчи **не** входит — по договорённости позже.
- После крупных патчей игры возможны поломки API — адаптация отдельно.
- Риск бана на стороне игрока.

## Dev / Playwright (опционально)

Для отладки без Tampermonkey:

```bash
npm install
npm run install:browsers
# .env: LOGIN, PASSWORD, MODE=forest|chaos|both
npm run forest
```

См. `src/` и `docs/PROTOCOL.md`.
