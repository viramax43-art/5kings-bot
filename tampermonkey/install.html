5Kings Bot v1.2.0 → Tampermonkey

Chrome 138+ не запускает скрипты TM, пока не включён тумблер «Разрешить пользовательские скрипты». Без него файл в редакторе сохраняется, но на сайте ничего не происходит.
  1. Откройте страницу Tampermonkey (если ссылка не открывается — вставьте в адресную строку chrome://extensions → Tampermonkey → Подробнее).
  2. Включите «Разрешить пользовательские скрипты». Если TM выключен — включите его.
  3. Нажмите кнопку ниже — Tampermonkey предложит установить/обновить скрипт.
  4. Откройте https://5kings.ru/game.html и обновите страницу (F5). Сверху зелёная полоса, справа панель.

Установить / обновить в Tampermonkey Открыть настройки TM

Либо вручную: Tampermonkey → создать скрипт → вставить весь файл 5kings-bot.user.js (версия 1.2.0) → Ctrl+S.
